

A tabela `access` organiza os acessos dos [[roles]] aos [[Eventos Mimic]], servindo para mapear quais [[entities]] um usuário poderá invocar em eventos.

## Estrutura

| Nome da Coluna      | Tipo                          | Constraints                     | Descrição                                                                                                                                                                                                                                 |
| ------------------- | ----------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id_access           | uuid                          | PK, FK -> [[entities]]          | Identificador único do registro desta tabela.                                                                                                                                                                                             |
| id_entity_to_access | uuid                          | nullable, FK -> [[entities]]    | Filtra a configuração de acesso apenas para essa entidade. Ao manter null, serve como configuração padrão para qualquer entidade.                                                                                                         |
| id_game_state       | uuid                          | nullable, FK -> [[game_states]] | Filtra a configuração de acesso apenas para esse game_state ativo. Ao manter null, serve como configuração padrão para qualquer game_state.                                                                                               |
| scope               | enum("self", "same", "other") | -                               | Escopo que o acesso se aplica:         \| "self" > "apenas para os criados pelo próprio usuário" \|                      \| "same" >  "apenas para os criados pelo mesmo role"\|                                \| "other" > "qualquer"\| |
| can_read            | boolean                       | -                               | Define se tem permissão para o evento 'read'                                                                                                                                                                                              |
| can_use             | boolean                       | -                               | Define se tem permissão para o evento 'use'                                                                                                                                                                                               |
| can_update          | boolean                       | -                               | Define se tem permissão para o evento 'update'                                                                                                                                                                                            |
| can_create          | boolean                       | -                               | Define se tem permissão para o evento 'create'                                                                                                                                                                                            |
| can_delete          | boolean                       | -                               | Define se tem permissão para o evento 'delete'                                                                                                                                                                                            |
| can_overwrite       | boolean                       | -                               | Define se tem permissão para o evento 'overwrite'                                                                                                                                                                                         |
