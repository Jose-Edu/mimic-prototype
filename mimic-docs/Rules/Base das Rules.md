A estrutura base inicia com alguns metadados e o campo `root` que armazena a árvore propriamente dita. Os nós sempre tem esse exato formato apresentado. Qualquer objeto: `{}` será interpretado como um novo nó.

	{
	    "mimic-version": '1.0.0',
	    "rule-type": '',
		 "return_type": '',
		 "return_struct": '',
	    "root": {
	        "operation-type": '',
	        "operation": '',
			"return_type": '',
			"return_struct": '',
	        "arguments": [
	
	            {
	                "operation-type": '',
	                "operation": '',
	                "arguments": []
	            }
	        ]
	    }
	}
